# ALPS — Algorithms and Libraries for Physics Simulations

The ALPS software package aims to provide a set of well tested, robust, and standardized components for numerical simulations of condensed matter systems, including bosonic, fermionic, and spin systems. They consist of a set of components that are used in state-of-the-art high performance codes.

**Project website:** [alps.comp-phys.org](https://alps.comp-phys.org/)

## Installation

For binary and Spack installation instructions, see the [ALPS installation website](https://alps.comp-phys.org/install/). To build this repository's C++ SDK and Python package from source, follow the [development setup](CONTRIBUTING.md#getting-started-with-the-code); [CHANGELOG.md](CHANGELOG.md) lists the migration steps for existing source builds and downstream projects.
